# AutoMagic Wallpapers (Free)

An Android wallpaper app that rotates your home screen background on a
schedule, either from bundled art or from a folder you pick on the device.

Package: `net.xenopro.automagicwallpapers` — version 1.2 (versionCode 4).

## Features

- Scheduled wallpaper rotation via a background service, restarted on boot
- Browse bundled categories in a grid, list or full-screen pager
- Pick any folder on the device as a wallpaper source
- Wikipedia info lookup for the bundled public-domain artwork
- Configurable rotation interval, Wi-Fi-only and shuffle options

## Building

This is an Eclipse/ADT-era project, predating Gradle and Android Studio.
It targets `android-18` with `minSdkVersion 9`.

Two things are missing from this tree and are needed to build:

- **ActionBarSherlock** — `project.properties` expects it as a sibling
  library project at `../actionbarsherlock`.
- **`local.properties`** — generated by the SDK, points at your `sdk.dir`.

The manifest also still declares `HomeActivity` and `SplashActivity`, which
were removed from the source before this snapshot was taken.

## Third-party

- [Universal Image Loader](https://github.com/nostra13/Android-Universal-Image-Loader) 1.8.4
- Android Support Library v4
- Millennial Media SDK, TapForTap SDK — both ad networks are long defunct

The TapForTap publisher key has been replaced with
`YOUR_TAPFORTAP_API_KEY` in `AndroidManifest.xml`, `GridHomeActivity` and
`ImageListActivity`.

Bundled wallpapers are public-domain artwork and Pixabay images.
